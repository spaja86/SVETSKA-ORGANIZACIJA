# Vodič za doprinošenje

Hvala što razmatrate doprinos Svetskoj organizaciji! Vaš doprinos je dragocen i pomaže nam da ostvarimo našu misiju.

## Kako možete doprineti?

### 1. Predlaganje projekata
- Otvorite GitHub Issue sa oznakom "predlog projekta"
- Opišite svrhu i cilj projekta
- Navedite potrebne resurse i vreme

### 2. Učešće u postojećim projektima
- Pregledajte otvorene Issues
- Komentirajte na projektima koji vas interesuju
- Pridružite se diskusijama

### 3. Unapređenje dokumentacije
- Ispravljanje grešaka
- Dodavanje primera
- Prevodi na druge jezike

### 4. Tehnički doprinos
- Code review
- Razvoj funkcionalnosti
- Testiranje

## Proces doprinosa

### Koraci:

1. **Fork repozitorijuma**
   ```bash
   git clone https://github.com/spaja86/SVETSKA-ORGANIZACIJA.git
   ```

2. **Kreirajte branch**
   ```bash
   git checkout -b ime-vaseg-branch-a
   ```

3. **Napravite izmene**
   - Držite se postojećeg stila
   - Dokumentujte vaše promene
   - Testirajte kada je moguće

4. **Commit izmena**
   ```bash
   git add .
   git commit -m "Opis vaših izmena"
   ```

5. **Push na GitHub**
   ```bash
   git push origin ime-vaseg-branch-a
   ```

6. **Kreirajte Pull Request**
   - Opišite šta ste promenili
   - Referencujte relevantne Issues
   - Sačekajte review

## Standardi

### Commit poruke
- Koristite jasne i opisne poruke
- Pišite na srpskom ili engleskom jeziku
- Primer: "Dodavanje dokumentacije za novi projekat"

### Dokumentacija
- Koristite Markdown format
- Budite jasni i koncizni
- Dodajte primere gdje je moguće

### Kod ponašanja
- Budite poštovani prema svima
- Konstruktivna kritika je dobrodošla
- Fokusirajte se na zajednički cilj

## Pitanja?

Ako imate pitanja:
- Otvorite GitHub Issue
- Kontaktirajte organizatore
- Pogledajte postojeću dokumentaciju

## Zahvalnica

Hvala vam što doprinosite boljitku čovečanstva kroz našu organizaciju! 🌍
