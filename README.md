## 🌍 Za dobrobit čovečanstva

SVETSKA ORGANIZACIJA je najveća i najjača globalna platforma posvećena unapređenju kvaliteta života za sve ljude na planeti. Naša vizija je svet u kome svako ima pristup osnovnim potrebama, obrazovanju, zdravstvenoj zaštiti i mogućnostima za lični razvoj.

## ✨ Karakteristike

- 🌐 **Globalni doseg** - Radimo sa zajednicama širom sveta
- 🤝 **Saradnja** - Povezujemo ljude, organizacije i resurse
- 💡 **Inovacije** - Primenjujemo najnovija rešenja za globalne izazove
- ❤️ **Humanost** - Stavaljamo ljude i njihove potrebe na prvo mesto

## 🚀 Početak rada

### Preduslovi

Za pokretanje ove platforme potreban vam je samo web browser.

### Instalacija

1. Klonirajte repozitorijum:
```bash
git clone https://github.com/spaja86/SVETSKA-ORGANIZACIJA.git
```

2. Otvorite `index.html` u vašem web browseru:
```bash
cd SVETSKA-ORGANIZACIJA
# Otvorite index.html u browseru
```

### Deployment

Za deployment na GitHub Pages:

1. Idite na Settings > Pages u vašem GitHub repozitorijumu
2. Izaberite branch (main) i folder (root)
3. Kliknite Save

Sajt će biti dostupan na: `https://spaja86.github.io/SVETSKA-ORGANIZACIJA/`

## 🎯 Naša Misija

### Osnažavanje zajednica
Pružamo podršku lokalnim zajednicama da razviju održive programe i inicijative koje unapređuju kvalitet života.

### Obrazovanje za sve
Omogućavamo pristup kvalitetnom obrazovanju i mogućnostima za učenje tokom celog života.

### Zdravstvena zaštita
Radimo na poboljšanju pristupa zdravstvenoj zaštiti i promociji preventivne medicine.

### Održivi razvoj
Promovišemo ekološki održive prakse i zaštitu životne sredine za buduće generacije.
