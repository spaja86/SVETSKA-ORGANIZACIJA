# Domain regulatory

## Svrha

Početni skelet za modele jurisdikcija, pravila, ograničenja i izuzetaka.

## Sadržaj paketa

- entiteti: jurisdikcija, pravilo, blokada, izuzetak
- statusi: `draft`, `active`, `superseded`, `blocked`
- validacije: važenje pravila, override razlog, veza sa create korakom
