# Domain profile

## Svrha

Početni skelet za modele profila, identiteta i dokaza.

## Sadržaj paketa

- entiteti: profil, identitet, dokaz
- statusi: `draft`, `active`, `pending-review`, `suspended`, `archived`
- validacije: obavezna polja, poreklo dokaza, veza sa korisnikom
