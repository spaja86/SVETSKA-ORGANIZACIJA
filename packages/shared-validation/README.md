# Shared validation

## Svrha

Deljene validacije i kontrolna pravila za profile, dokaze, procene, licence i regulatorne blokade.

## Minimalni sadržaj

- validacije obaveznih polja i identifikatora
- validacije porekla dokaza i dozvoljenih prelaza statusa
- pravila za `validation-error`, `regulatory-block` i `review-required`
