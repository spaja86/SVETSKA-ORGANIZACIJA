# Domain assessment

## Svrha

Početni skelet za modele procene, rezultata, odluka i žalbi.

## Sadržaj paketa

- entiteti: zahtev za procenu, rezultat, odluka, žalba
- statusi: `requested`, `in-review`, `awaiting-human-review`, `approved`, `rejected`, `appealed`
- validacije: kriterijumi procene, ručna revizija, konzistentnost odluke
