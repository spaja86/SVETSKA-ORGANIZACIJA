# Domain partner

## Svrha

Početni skelet za modele partnera, angažmana, akreditacije i potvrda.

## Sadržaj paketa

- entiteti: partner, akreditacija, angažman, potvrda
- statusi: `invited`, `active`, `restricted`, `inactive`
- validacije: pravila uloge, aktivna akreditacija, sporni angažman
