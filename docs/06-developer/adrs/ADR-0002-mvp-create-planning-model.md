# ADR-0002: MVP create plan kao obavezni most između dokumentacije i implementacije

## Status

Usvojeno

## Kontekst

Repozitorijum ima stabilnu dokumentacionu osnovu, ali je za prelazak u MVP implementaciju potrebno uvesti jedinstven razvojni model koji povezuje zahteve, domene, ugovore, testove i audit kontrole.

## Odluka

Usvajamo MVP create plan, traceability matricu, definition of ready i release model kao obavezne tehničke mehanizme pre otvaranja većih implementacionih radova.

Minimalni create tok postaje prioritetna implementaciona nit kroz profile, dokaze, procenu, licencu, pregled statusa i audit zapis.

## Posledice

- tehničke odluke dobijaju jasan ulaz iz strategije, produkta i politika
- budući API ugovori, deljeni modeli i testovi nastaju iz istog izvora istine
- bezbednost, usklađenost i audit postaju sastavni deo planiranja, a ne naknadni dodatak
