# ADR-0001: Struktura repozitorijuma kao višeslojna dokumentaciona i tehnička osnova

## Status

Usvojeno

## Kontekst

Repozitorijum je započeo kao jedan obiman `README.md`, što nije bilo dovoljno za održavanje strategije, operacija, produkta i tehničke osnove kroz vreme.

## Odluka

Uvodimo numerički organizovanu strukturu dokumentacije i zaseban skelet za budući kod, API specifikacije i testove.

## Posledice

- lakša navigacija i održavanje
- jasnije granice između dokumentacionih slojeva
- spremnost za postepeni prelazak ka implementaciji bez mešanja domena
