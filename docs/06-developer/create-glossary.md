# Rečnik create pojmova

## Svrha

Jedinstveni jezik create domena smanjuje kontradikcije između dokumentacije, ugovora, paketa, servisa i testova.

## Pojmovi

- **profil** — osnovni zapis o korisniku i njegovim kompetencijama u create toku
- **dokaz** — artefakt ili tvrdnja koja potkrepljuje kompetenciju, identitet ili uslov za procenu
- **procena** — proces provere dokaza i kriterijuma koji vodi do rezultata
- **rezultat procene** — preliminarni ili potvrđeni ishod procene
- **ručna revizija** — ljudska potvrda ili korekcija odluke kada automatizacija nije dovoljna
- **licenca** — odobrenje za rad ili statusno definisano pravo koje nastaje iz create toka
- **partner** — eksterni ili interni akter ovlašćen da učestvuje u proceni, potvrdi ili angažmanu
- **audit događaj** — neizmenjiv zapis o poslovnom koraku, odluci, blokadi ili izuzetku
- **regulatorna blokada** — pravilo koje sprečava nastavak create toka bez dodatne odluke ili zabrane
- **korelacioni identifikator** — zajednički identifikator koji povezuje događaje jednog create slučaja
