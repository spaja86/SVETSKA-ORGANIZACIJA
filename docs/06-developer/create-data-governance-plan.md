# Plan upravljanja podacima za create tok

## Svrha

Ovaj dokument povezuje profile, dokaze, procene i licence sa minimalnim pravilima upravljanja podacima.

## Obavezna pravila

- prikuplja se samo podatak potreban za konkretan korak create toka
- svaki dokaz mora imati poreklo, status i pravilo retencije kada je relevantno
- pristup podacima prati model dozvola i ostavlja audit trag
- deljeni modeli i ugovori moraju eksplicitno označiti osetljive podatke

## Kontrolne tačke

- validnost i minimizacija podataka pri kreiranju profila
- retencija i vlasništvo pri unosu dokaza
- pravičnost i proverljivost pri proceni i odluci
- konzistentnost istorije i statusa pri licenciranju
