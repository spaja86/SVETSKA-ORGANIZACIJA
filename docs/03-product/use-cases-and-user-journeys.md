# Use cases i user journeys

## Glavni use cases

- osoba otvara profil i unosi dokaze o znanju
- evaluator sprovodi procenu i potvrđuje rezultat
- partner dodeljuje obuku ili praksu
- sistem izdaje licencu ili vraća korisnika na korektivnu putanju
- poslodavac ili partner proverava validnost licence
- administrator prati KPI, rizike i žalbe

## Ključne korisničke putanje

### Putanja kandidata
profil → procena → obuka/praksa → licenca → rad → obnova

### Putanja partnera
akreditacija → pristup kandidatima → dodela obuke ili angažmana → potvrda učinka

### Putanja regulatora
pregled standarda → lokalna pravila → nadzor usklađenosti → revizija odluka
