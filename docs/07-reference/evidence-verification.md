# Verifikacija dokaza znanja i rada

## Izvori dokaza

- formalno obrazovanje
- praktičan rad i portfolio
- verifikovani projekti i zadaci
- preporuke mentora i partnera
- standardizovane procene

## Pravilo

Dokazi moraju biti proverljivi, vezani za kompetenciju i dostupni za audit u meri dozvoljenoj pravilima pristupa.
