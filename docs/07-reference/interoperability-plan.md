# Plan interoperabilnosti

## Cilj

Omogućiti standardizovanu razmenu podataka sa državama, školama, univerzitetima, kompanijama i digitalnim platformama bez gubitka audit traga i kontrole pristupa.

## Prioriteti

- standardni identifikatori
- razdvojeni javni i privatni podaci
- verzioniranje ugovora i mapiranja
- dokaziv status licenci i akreditacija
