# Dependency map

## Ključne zavisnosti

- programi zavise od standarda kompetencija i merenja učinka
- procena zavisi od profila, dokaza i evaluacionih pravila
- licenca zavisi od rezultata procene, regulatornih zahteva i statusa obuke
- angažman zavisi od validne licence kada je primenljivo
- AI preporuke zavise od kvalitetnih podataka, audit traga i ljudske supervizije
