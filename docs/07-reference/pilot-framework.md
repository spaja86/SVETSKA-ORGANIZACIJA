# Okvir za pilot-projekte

## Fokus pilota

- prioritetne i univerzalne delatnosti
- ograničen broj regiona i partnera
- visoka vidljivost KPI, žalbi i audit traga

## Merila uspeha pilota

- vreme od prijave do prve licence
- kvalitet procene i procenat korekcija
- uspešno povezivanje sa radom ili praksom
